# Security Policy

## Supported versions

Security fixes are applied to the latest code on the default branch. Released builds receive fixes on a best-effort basis; users should update to the latest available release.

## Reporting a vulnerability

Please do **not** disclose vulnerabilities in a public issue, discussion, or pull request.

Use GitHub's private vulnerability reporting through the repository's **Security** tab, or open a private report at:

https://github.com/drgnchan/Voxwrite/security/advisories/new

Include, when possible:

- A description of the issue and its impact.
- A minimal reproduction or proof of concept.
- Affected platforms and versions.
- Suggested mitigations, if known.

Remove API keys, personal recordings, private text, and other sensitive information before submitting. We aim to acknowledge reports within seven days and will coordinate disclosure after a fix is available.

Security-sensitive areas include credential storage, microphone or text disclosure, unsafe endpoint handling, input-method behavior, and unintended interaction with other applications. Vulnerabilities in a third-party cloud provider should also be reported directly to that provider.
