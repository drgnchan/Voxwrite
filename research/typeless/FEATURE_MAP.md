# Typeless 行为盘点与独立实现规格

> 目标：独立实现一款具有相同核心工作流的 macOS 语音写作助手；不提取 Typeless 私有源码，不复用其品牌、图标或受保护素材。

## 已观察版本

- Typeless v2.2.1
- macOS 桌面应用（Electron）
- 盘点日期：2026-08-05
- 运行证据：`research/typeless/screenshots/`

## 核心体验

### 1. 全局语音输入

- 默认快捷键：`Fn`
- 按住 Fn 时，在屏幕底部显示快捷键教学/模式选择浮层。
- 松开后进入语音输入状态。
- 再按 Fn 结束录音并进入 `Thinking` 处理状态。
- 处理完成后应将整理后的文本写入当前应用的聚焦输入框。
- 核心价值不是逐字转写，而是把口语、停顿、重复和零散想法整理成清晰文字。

### 2. 翻译

- 默认快捷键：`Fn + Left Shift`
- 以自然语言口述，输出清晰、地道的目标语言文本。
- 设置中最多可选择 3 种翻译目标语言。

### 3. 问答与文本编辑

- 默认快捷键：`Fn + Space`
- 可针对当前选中文本进行编辑或提问。
- 历史记录中可保存问题，并通过“查看答案”查看结果。

### 4. 悬浮交互

- 浮层固定在屏幕底部中央附近。
- 快捷键教学浮层会列出口述、翻译、问答三种模式。
- 录音态为紧凑胶囊；停止后显示 `Thinking`。
- 处理态包含左右图标按钮，需在实现阶段定义为取消、重试或确认等明确动作，并提供可访问性标签。

## 主窗口

### 首页

- 三种模式说明和快捷键提示。
- Gmail、Slack、ChatGPT、Google Docs、WhatsApp、Claude、Notion 等使用场景。
- 用量统计：使用时长、输出字数、每分钟字数、节省时间等。
- 免费额度与升级入口。

### 历史记录

- 分类：全部、听写、问任何问题。
- 按日期和时间分组。
- 问答条目支持“查看答案”。
- 历史保留期可配置，当前界面支持“永远”。
- 产品宣称历史仅存储在本机。

### 词典

- 分类：所有、自动添加、手动添加。
- 可手动录入专有名称和词汇。
- 可从用户对转写结果的编辑中自动学习词汇。

## 设置

### 快捷键

- 语音输入
- 翻译
- 随便问
- 支持自定义组合键

### 语言

- 界面语言
- 最多 3 个翻译目标语言
- 语言变体

### 音频

- 麦克风选择和自动检测
- 交互声音
- 语音输入时自动静音其他音频

### 常规

- 外观：浅色、深色、跟随系统
- 登录时启动
- 是否在 Dock 中显示

### 个性化

- 展示整体个性化百分比。
- 根据用户修改逐步学习写作偏好。
- 当前账号数据不足时显示对应空状态。

## 建议技术架构

### macOS 客户端

- Swift 6 + SwiftUI
- AppKit：无焦点悬浮窗、菜单栏应用、全局键盘事件、Dock 策略
- CoreGraphics event tap：监听 Fn 及组合键
- AVAudioEngine：麦克风采集、音量检测和音频分段
- Accessibility API：读取选中文本、向当前聚焦控件写入结果
- Pasteboard + 合成粘贴：无法直接通过 AX 写入时的降级路径
- SQLite：本地历史、词典、偏好和统计
- Keychain：API 密钥和敏感配置

### AI 管线

1. 音频采集与静音检测
2. ASR 转写
3. 根据模式执行清理、翻译、问答或改写
4. 应用上下文与个人词典修正
5. 写回当前应用
6. 本地记录元数据和可选历史

ASR 和语言模型应设计成可插拔 Provider：

- 本地优先：WhisperKit / whisper.cpp
- 云端优先：兼容 OpenAI 风格 API 的 ASR 与 LLM
- 混合模式：本地转写、云端润色

## 建议交付阶段

### Phase 1：个人使用 MVP

- 菜单栏常驻
- Fn 全局快捷键
- 录音与底部悬浮状态
- 中英文语音识别
- 去口头禅、标点和结构化整理
- 将结果写入当前应用
- 本地历史和基础设置

### Phase 2：完整核心功能

- 翻译模式
- 读取选中文本并执行问答/改写
- 手动与自动词典
- 麦克风、语言、快捷键配置
- 本地统计

### Phase 3：个性化与产品化

- 从修改中学习写作偏好
- Provider 管理和隐私选项
- 自动更新、签名、公证和安装包
- 可选账号、同步、额度或订阅系统
